# Attentive iOS SDK 0.1.0-staging.1

Private binary staging release. Install through Swift Package Manager using
`https://github.com/OdionAI/attentive-ios-sdk.git` and exact version
`0.1.0-staging.1`. Your GitHub account needs read access to this repository.

## Included

- `AttentiveVoice`: headless call controls, audio, transcripts, authentication
  events and tool activity for your own UI.
- `AttentiveVoiceUI`: optional SwiftUI caller screen using the same core.
- Required native frameworks, resources, privacy manifests and third-party
  notices. Implementation Swift source is not distributed; public interfaces,
  native identifiers and required attribution remain visible.
- Human quickstart, optional UI guide and coding-agent integration instructions
  in the repository root.

## Requirements

- Xcode 26.6 / Swift 6.3.3. Older compiler compatibility is not claimed.
- Core: iOS 16+. Optional UI: iOS 17+.
- iPhone arm64; Simulator arm64 and x86_64.
- A reachable Attentive call API and realtime service. The API endpoint is
  supplied by the host app, not hardcoded into the SDK.

## Staging Limitations

This publication does not deploy a backend. Local staging requires reachable
Mac LAN addresses for a physical iPhone; `localhost` on a phone is the phone
itself. Do not ship local HTTP exceptions or POC identity settings in production.

The source-built iPhone app previously passed the user's manual call check.
A physical-iPhone live-call test of this published binary package is still
pending. Signing, App Store compliance and full audio/authentication/tool
regression acceptance are not claimed by this prerelease. Attentive frameworks
are unsigned staging artifacts; the host app must handle its own signing.

No backend, model, tool, voice-authentication policy or physical-phone app was
changed for this release. Gateway, gRPC and Android SDK work remain separate.

Keep this tag immutable. Any package fix must receive a new version.
