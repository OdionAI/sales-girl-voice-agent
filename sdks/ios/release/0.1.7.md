# iOS SDK 0.1.7 — passkey presentation and retry reliability

- Keep a valid native passkey credential after Face ID succeeds even if the host
  window or scene changes while AuthenticationServices displays its sheet.
- Report bounded diagnostics for a missing presentation anchor, inactive scene,
  or hidden window when the SDK cannot start a prompt.
- Generate a fresh correlation ID for every ceremony, allowing a new passkey
  attempt for the same still-prepared operation after a prior attempt fails.
- The bank still verifies each proof, and no failed or cancelled ceremony
  authorizes a transaction.

See [passkey integration](../PASSKEYS.md).
