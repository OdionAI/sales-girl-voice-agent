# iOS SDK 0.1.6 — voice preferences

- Add optional `VoiceAccent` (`en-NG` / `en-US`) and `VoiceGender` (`female` / `male`).
- Configure `voiceLanguage` / `voiceGender` through all `AttentiveAgentView` and
  API-key `AttentiveCall` initializers, or per advanced `CallRequest`.
- Both defaults are `nil`, so existing call payloads and server-selected voices
  are preserved. Exact camelCase JSON keys are emitted only when set.
- Runtime `language`, identity, passkeys, audio input and the supplied UI are unchanged.
- Voice selection requires a compatible service and provisioned voices; no voice
  identifiers or model credentials are sent from the app.

See [configuration](../VOICE_SETTINGS.md).
