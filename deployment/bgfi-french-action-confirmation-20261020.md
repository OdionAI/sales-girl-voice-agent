# BGFI French action confirmation hotfix — 2026-10-20

## Cause

The 2026-10-20 second-most-recent Claire / BGFIBank Bénin call showed that
normal model responses were in French, but the RVC worker generated its ticket
confirmation as a fixed English application phrase. The worker also failed to
classify the caller's clear “Okay, create the ticket” response as approval, so
it repeated that English question. The ticket confirmation is generated by
`latency_lab/action_tools.py`, outside the agent's LLM prompt.

## Change and release

- Runtime language is now read from the agent-config response's
  `tts_language_hint`.
- Ticket and email confirmation questions, acknowledgements, and success or
  failure messages use French when the saved hint is French.
- Confirmation classification recognizes accented French approvals and
  refusals, along with a clear English approval such as “Okay, create the
  ticket.”
- Source code commit: `52988d2245c28841041b638248e11270fbeb1c9f`.
- Release overlay commit: `70109399a0a9fe76cfaf0a756a7eea9cf01ab612`.
- Source snapshot on the VM:
  `/opt/attentive/releases/recovery-20261009/sources/bgfi-french-confirmation-52988d2`.
- Image: `attentive/voice:bgfi-french-action-confirmation-20261020-1`.
- Only `odion-recovery-lagos-voice-1` was recreated. Other stack services and
  their settings were left as they were.

## Verification

- `python3 -m unittest latency_lab.tests.test_action_tools` passed (9 tests).
- The live container reports `running` on the new image and registered
  `rvc-livekit-comparison` with LiveKit.
- A runtime-config read for Claire returned `loaded=true` and
  `language_hint=French`.
- The running image produced a French ticket confirmation and classified
  “Okay, create the ticket” and “Oui, créez le ticket” as confirmed, and
  “Non, merci” as rejected.
- A new live BGFI call should still be used to verify the full spoken ticket
  creation flow end to end.
